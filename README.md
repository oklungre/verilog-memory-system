# Verilog Memory System

Verilog-based digital design project implementing and verifying a modular memory system.

The project includes:
- finite state machine control logic
- decoder logic
- bitcell and word modules
- array structure
- memory system integration
- verification testbenches
- simulation outputs from Active-HDL

## Technologies
- Verilog
- Active-HDL

## Structure
- `*.v` — Verilog source modules
- `*_tb.v` — verification testbenches
- `*.PNG` — simulation screenshots
